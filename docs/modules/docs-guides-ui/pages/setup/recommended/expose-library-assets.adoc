[#expose-library-assets]
= Expose Library Assets

An application integrated with OneCX still loads and runs without exposing the assets of the OneCX libraries it depends on, but it behaves incorrectly: missing static assets (e.g. icons) shipped by those libraries. Because Micro Frontends are loaded relative to the shell rather than from their own origin, library assets need to be exposed through the application's own build output using a dedicated mechanism, rather than assuming they're resolvable from the library's package location.
