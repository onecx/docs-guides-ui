[#expose-component-styles]
= Expose Component Styles

An application integrated with OneCX still loads and runs even if its own or its libraries' styles aren't exposed correctly, but it renders with visibly wrong styles: missing layout or unstyled components. This page covers exposing an application's and its OneCX libraries' styles in the build output, so the shell can style the app correctly.
