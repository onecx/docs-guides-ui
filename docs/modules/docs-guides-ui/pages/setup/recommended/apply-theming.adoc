= Apply Theming

The OneCX shell loads and applies the active theme for the selected workspace. Application code should not load or apply the theme itself; it should use the CSS variables the shell exposes.

See xref:documentation:docs-guides-ui:concepts/theming.adoc[Theming] for the full list of available theme variables and how to use them in Angular and React applications.
