[#platform-package-compatibility-requirements]
= Platform & Package Compatibility Requirements

Before an application can be loaded by the OneCX shell, it must satisfy a baseline of platform and package compatibility constraints.

[#angular-version-compatibility]
== Angular Version Compatibility

The application's Angular version must be equal to or lower than the version used by the shell (or, for shell-loaded technology preloaders, the respective preloader).

* Check the shell version and ensure the app uses an equal or lower Angular version. See xref:documentation:onecx-shell-ui:onecx-shell-ui-docs.adoc#shell-version-information[Shell Version Information] for how to check the shell's supported version.

[#package-sharing-convention]
== Package Sharing Convention

Use the caret (`^`) range for all shared package versions in `package.json`, except `rxjs`, which should use tilde (`~`).

See xref:documentation:docs-guides-ui:setup/required/configure-remote-package-sharing.adoc[Configure Remote Package Sharing] for the list of packages that must be shared and the recommended utility for applying OneCX sharing settings.
