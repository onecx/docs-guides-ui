[#migrating-an-existing-app]
= Migrating an Existing App

This section covers bringing an existing Angular application to OneCX. Pick the branch that matches your starting point.

[#start-from-vanilla]
== Start from a vanilla app
Use this branch when the application is not yet a OneCX app. Pick the guide that matches the OneCX platform library version you are integrating against.

* xref:documentation:docs-guides-ui:migration/vanilla-to-onecx-angular.adoc[Migrate a vanilla Angular app to OneCX] — targets Angular 21 and OneCX UI libraries v8 and cross-links into the setup pages rather than restating their steps. To reach a newer version afterwards, follow the upgrade guides below, starting with Angular 22.
* xref:documentation:docs-guides-ui:angular/app-to-onecx.adoc[Migrate vanilla Angular apps to OneCX (legacy guide)] — targets Angular 18 and OneCX UI libraries v5. Use it only if the app cannot be upgraded to Angular 21 first, then follow the upgrade guides below, starting with Angular 19.

[#upgrade-an-existing-onecx-app]
== Upgrade an existing OneCX app
Use this branch when the application is already a OneCX app and needs to be upgraded across OneCX platform library versions. Each Angular major version requires a specific major version of the OneCX UI libraries, so upgrade one version at a time and follow the guide for each version you are moving to:

|===
| Angular version | OneCX UI libraries | Guide

| 19
| v6
| xref:documentation:onecx-portal-ui-libs:migrations/angular-19/index.adoc[Upgrade to Angular 19]

| 20
| v7
| xref:documentation:onecx-portal-ui-libs:migrations/angular-20/index.adoc[Upgrade to Angular 20]

| 21
| v8
| xref:documentation:onecx-portal-ui-libs:migrations/angular-21/index.adoc[Upgrade to Angular 21]

| 22

| 23

|===
