= Troubleshooting

Troubleshooting helps you diagnose and resolve common problems when building, integrating, or running OneCX UI applications. This section is organized by the stage of the issue: preparation steps to run first, followed by application setup, shell compatibility, general causes, specific errors, and tsconfig path-alias errors.

Start with the xref:documentation:docs-guides-ui:troubleshooting/preparation.adoc[Preparation] page and work through the sections until you find the fix for your problem. Each page is a standalone entry point and links to the canonical guides for the details.
