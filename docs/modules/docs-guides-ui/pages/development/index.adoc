= Development

This section holds pages that help while developing and debugging a OneCX UI application. They do not change how the application behaves at runtime.

== Pages

* xref:documentation:docs-guides-ui:development/browser-logging.adoc[Browser Logging] — how to turn on the `debug-js` logging of the OneCX UI libraries in the browser and filter it by library, location and log level.
