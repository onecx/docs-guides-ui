# docs-guides-angular

## Troubleshooting

The Antora module `docs-guides-ui` includes a standalone Troubleshooting page set under `docs/modules/docs-guides-ui/pages/troubleshooting/`. The set helps you diagnose and resolve common problems while building, integrating, and running OneCX UI applications:

- **Preparation** — the steps to complete before reporting an issue
- **General Issues** — cross-cutting causes, such as incomplete or incompatible shared packages
- **Application Setup** — app-side settings, such as the remote module name
- **Shell Compatibility** — package sharing between the shell and the application
- **Specific Issues** — specific, named errors and rendering problems
- **TSConfig Paths** — `tsconfig` path-alias errors
